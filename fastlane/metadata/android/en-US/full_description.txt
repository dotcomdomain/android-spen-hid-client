<p>This Android app turns your rooted Android device into a hardware USB HID input device for your computer. Because communication happens directly via the Linux USB gadget kernel driver (<code>/dev/hidg*</code>), your computer detects it as genuine plug-and-play USB hardware with zero drivers or client software required on the host!</p>

<p><b>Key Features:</b></p>
<ul>
<li><b>Samsung S Pen Drawing Tablet:</b> Use your phone as a high-precision graphics digitizer tablet with full pressure sensitivity (4096 levels), hover tracking, barrel button eraser toggle, customizable hover range, and orientation-aware coordinate mapping. Works seamlessly in Krita, Photoshop, Clip Studio Paint, Blender, OneNote, and any Windows/Linux application.</li>
<li><b>Windows Precision Touchpad (PTP):</b> Multi-touch touchpad emulation supporting smooth 1 to 5 finger gestures, tap-to-click, pinch-to-zoom, two-finger scrolling, and virtual desktop switching.</li>
<li><b>USB Keyboard &amp; Mouse:</b> Direct keyboard input, scriptable keystrokes, and standard mouse mode with left/right buttons and scroll wheel. Functions even inside your computer's BIOS/UEFI.</li>
<li><b>Modern Material 3 Interface:</b> Dynamic color theming, configurable display modes (fullscreen, hide status bar, hide app bar), and customizable digitizer settings.</li>
<li><b>Full Virtual Keyboard:</b> Function keys, navigation keys and multitouch modifier holds, with optional sticky modifiers.</li>
<li><b>Offline Voice Dictation:</b> An optional, remappable hardware-button hold records speech and types its transcription over USB. Download the Whisper base model separately from Hugging Face in Settings. Choose replacement, queued or parallel processing with ordered text delivery. Disabled by default; audio stays on the phone.</li>
</ul>

<p><b>Requirements:</b></p>
<ul>
<li>Root access (KernelSU, APatch, or Magisk) to access USB HID gadget character devices.</li>
<li>Kernel with USB HID Gadget support enabled (standard on most modern Android devices).</li>
</ul>

<p>For more details on setup, custom scripts, and troubleshooting, visit the project repository on GitHub.</p>

<p>This app is a fork of Arian04/android-hid-client, with added S Pen input, Windows precision touchpad support, a full virtual keyboard and optional offline voice dictation. Source code and bug reports for this fork are available at <a href="https://github.com/dotcomdomain/android-spen-hid-client">its project repository</a>.</p>
